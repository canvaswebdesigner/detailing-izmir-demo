# Detailing İzmir — Demo

Tüzün Bey / Detailing İzmir için hazırlanmış statik tanıtım sitesi.

## Kapsam

- Tek sayfalık, mobil öncelikli demo
- Gerçek fotoğraflar gelene kadar bilinçli olarak boş portfolyo alanları
- WhatsApp, telefon ve Google Maps bağlantıları
- Google değerlendirme özetleri
- Özel 404 hata sayfası
- Arama motorlarına kapalı demo yayını
